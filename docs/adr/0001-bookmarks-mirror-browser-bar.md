# 书签只读镜像浏览器书签栏

---
status: accepted
date: 2026-11-01
---

扩展不再自存书签。旧机制把书签列表存在 `chrome.storage`（含默认书签与版本迁移），现已整体废弃；书签的唯一数据源是浏览器「书签栏」这棵树，新标签页通过 `chrome.bookmarks` 只读镜像渲染并监听变更实时刷新。

原因：浏览器本身就是书签管理器，双份数据必然漂移；双向同步则是重复建设且引入冲突问题。权衡过的替代方案——保留默认书签作回退、做「浏览器/自定义」双模式开关——都因维护两套数据路径被否决。代价：需新增 `"bookmarks"` 权限（安装时出现读取书签警告），书签栏为空时只能显示引导文案而非默认数据。

## Consequences

- 旧用户的 storage 书签数据在升级后不再展示，且无迁移（有意为之：旧数据仅是十来条写死的默认项）。
- `defaultBookmarks`、`BOOKMARKS_VERSION` 及全部迁移代码随之删除。
